```markdown
### ✏️ Thay đổi code
- [MODIFY] file_path: thay đổi gì, dòng nào
- [NEW] file_path: mô tả file mới
- [DELETE] file_path: lý do xóa

### 💡 Quyết định thiết kế
- Các lựa chọn đã cân nhắc
- Lý do chọn phương án cuối cùng

### 📊 Kết quả
- Trạng thái dự án sau khi hoàn thành
- Lỗi còn tồn tại (nếu có)
```
